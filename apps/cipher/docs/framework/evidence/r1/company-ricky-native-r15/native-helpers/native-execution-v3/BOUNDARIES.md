Original-author session/CSRF authentication is sequential and genuine. Each wire has its own opener, bounded body, original UUID and official request/response schema validation. Require one first-effect winner, one `draft_already_saved` loser, one real application/canonical successor and unchanged original preparation. An incomplete batch or unknown outcome is retained and blocks qualification; no replacement UUID is minted.
8. `audit(path, final_queue)` requires every distinct boundary case passed and independently empty active Run/queue/worker/started inventory. It composes all R15 command/result-derived additions, exact original typed rows, config/source/index and cookie/R14 evidence preservation, only the three literal supported restoration audit deltas, and the one exact two-operation overlap batch. It cannot accept arbitrary old-row exceptions. The retained batch stays explicitly labeled `verified-batch`; only the private audit view normalizes that already verified aggregate for the frozen v2 heartbeat verifier.

The current large v2 manifest is preserved; repeated full per-case inventories are kept out of it. No listener, backup, migration, service/worker restart, grant-authority override, native master creation, acceptance, financial/model/provider/award action or publication is performed by these helpers.
