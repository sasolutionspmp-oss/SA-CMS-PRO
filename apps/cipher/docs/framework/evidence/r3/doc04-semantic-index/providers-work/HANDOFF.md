# DOC04 optional semantic provider clients

Only semantic_index/http.py, semantic_index/providers.py and tests/test_semantic_index_providers.py are owned source. Root owns package initialization, contracts/configuration/ledger/source authorization/jobs/API/schema and integration. Endpoints, model pin, collection and optional Qdrant API key are server configuration; no RPC URL/model overrides, credential discovery, provider fallback or automatic collection/model setup.

OllamaEmbedder(endpoint, model_tag, model_digest, dimensions, *, protocol="ollama-embed-v1", timeout=10, max_body=4194304, transport=None). identity returns a fresh dictionary {provider:"ollama", protocol, model, model_digest:"sha256:<hex>", dimensions}. verify() reads /api/tags and /api/show; embed(list[str]) verifies each batch then calls /api/embed with truncate:false and checks exact model/batch/dimensions and finite nonboolean numbers. Remote forwarding fields are refused. Tags require an explicit tag and pinned SHA256 manifest digest. No pull/create endpoint is used.

QdrantIndex(endpoint, collection, dimensions, *, protocol="qdrant-rest-v1", timeout=10, max_body=4194304, api_key=None, transport=None). Methods verify(), upsert(points), delete(ids), query(vector,scope_key,profile_id,generation,limit), scroll(scope_key,profile_id,offset=None,limit=50). Every operation verifies a preprovisioned unnamed float32 Cosine vector collection of exact dimensions. Writes use wait=true and require completed status. query uses mandatory scope/profile/generation match filters; scroll uses scope/profile to reconcile old generations. Returned fields are only id/score/payload for query and id/payload for scroll; next_page_offset maps to next_offset. Payload keys are exactly scope_key,profile_id,generation,document_id,revision_id,source_sha256,chunk_id,page,excerpt_sha256,chunk_sha256. No text/snippets/vectors are returned to the service. Scope/profile and hashes are lowercase SHA256; generation and point IDs/offsets are canonical UUID strings; document/revision/chunk IDs are bounded140.

Bounds: embed/upsert<=16 items; each text<=16384 UTF8 bytes; dimensions<=8192; delete<=100 IDs; query<=100; scroll<=50; pages1..10000. Root must split larger ledger batches. Transport injection is an object request(method,path,payload=None)->decoded dict. Default JsonHttpClient uses real stdlib urllib with inherited proxy/TLS settings, no redirects/retries, bounded JSON request/response bodies (default4MiB, absolute8MiB), strict response type/encoding, duplicate-key/nonfinite JSON rejection, socket timeout<=30seconds and monotonic response-read deadline. No raw provider errors/body/log text is exposed. Safe errors are semantic_unavailable(503), semantic_protocol_error(502), semantic_invalid_input(422). Unavailable explicitly fails every operation.

Qualification:19 focused host protocol tests passed in 02-provider-protocol-fixture-corrected.log, injected transports plus one local HTTP JSON/redirect stub. 01-provider-protocol.log retains the initial test-double deepcopy(DomainError) setup failure; no product failure is misreported. No Ollama/Qdrant/model/native worker is connected or qualified.

Official references are hashed in PROTOCOL_REFERENCES.json: Ollama v0.12.6 api/types.go and docs/api.md; Qdrant v1.15.5 OpenAPI. These pin the reviewed protocol source, not an installed server version. /api/show embedding_length is checked from general.architecture and the corresponding architecture.embedding_length field. Ollama digest checks are provider-reported manifest identity, not cryptographic remote attestation; tag replacement between verification and inference cannot be atomically fenced by these HTTP endpoints. No model quality/cosine ranking/performance claim is made. Socket/read timeouts are bounded but process-level DNS/connect cancellation, provider write uncertainty/reconciliation, credentials/TLS/private-network setup and actual provider qualification remain operational/integration responsibilities. Root ledger must enforce generation ownership, join candidate digests to exact canonical source, reauthorize current access, bound full reconciliation/cursor traversal and handle uncertain derived-index writes.
