# Working drawing calibration

In a Company takeoff set, select an authorized PDF and current revision/page, then **Author working calibration**. Pick two anchors or enter exact original PDF coordinates; select a qualified length unit; enter known distance, arithmetic tolerance, title and basis; review the declared inputs and **Save unverified calibration**. This length-only basis declares no area/volume relation or conversion. Arithmetic tolerance is not survey or drawing uncertainty.

The actual PDF bytes/hash and frame govern coordinate selection. Saving remains unverified and does not authorize geometric quantities or engineering approval. A separate read checks the stored record/digest. **Browse saved calibrations** reopens the actual bases under current authority after navigation/reload. Current geometric eligibility and any independent verification fact are separate from immutable recorded status.

Before the first submit, current source metadata is checked. The canonical backend owns save-time admission. A confirmed changed working source clears old pixels/form. Unknown replies retain the original UUID/body in the mounted view; **Recover original takeoff request** reuses it. There is no cross-reload command journal. Permission loss, malformed reads and late replies hide old source-bearing details.
