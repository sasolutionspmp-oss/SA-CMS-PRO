# DOC-03 Project document control

Canonical Project APIs retain original Document Revision/File artifacts for library revisions, independently authorized adoptions and documentary issued sets, and separately authorized internal transmittals. Documentary receipt/execution reports do not sign, seal, deliver externally or execute a commercial contract.

Content-use permission revisions record the declared holder/purpose/restrictions, exact evidence artifact, explicit UTC validity dates and independent ingest/read/distribute flags. Current ordinary source access, permission validity and original evidence access govern retained bytes/text, replay and distribution. No-policy documents keep their existing path. Supporting evidence graphs are bounded and cyclic evidence is refused.
