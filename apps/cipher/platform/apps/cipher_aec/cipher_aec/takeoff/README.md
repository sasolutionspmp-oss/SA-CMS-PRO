# Source-bound takeoff (EST-02)

This domain records explicitly authored PDF geometry and manual quantities. It does not detect paths, infer scales, invoke a model, run CAD or perform OCR. Coordinates are PDF user space, with server-derived MediaBox/CropBox, orthogonal page rotation and UserUnit=1; screen pixels and unsupported page metadata are refused. The parser runs in a separate bounded process against the exact authorized stored bytes.

Calibration uses two known-distance anchors and one uniform similarity scale. The immutable calibration binds the exact source artifact revision/hash/page, page frame, qualified length unit, explicit reviewed squared/cubed output-unit relations, formula version and source citations. Derived-unit relations are local geometric transforms, never general cross-dimension Unit Conversion records. Compatible canonical same-dimension conversions must agree. Independent canonical human verification uses the shared static `calibration.verify.v1` governance action; aliases and arbitrary trusted writes cannot supply that approval.

Supported geometry is a segment/polyline length, axis-aligned rectangle or simple polygon area, and an authored positive-depth extrusion of a rectangle/polygon. Arcs, holes, intersecting/touching polygons, degenerate vertices, warped sheets and screen transforms are not supported. Up to 128 vertices are accepted. Coordinates are exact strings with at most six fractional places and absolute value at most 1,000,000, inside the PDF CropBox.

Area uses exact rational shoelace arithmetic and the exact squared calibration scale. Extrusion depth is converted through qualified same-dimension units before applying the explicit cubed output relation. Irrational lengths use rational lower/upper square-root bounds at 36/54/72 decimal places. A result is admitted only if both bounds round half-up to the same declared output precision. Calibration `relative_numeric_tolerance` is a dimensionless arithmetic interval-width/upper-result bound; measurement `tolerance` is an absolute bound in its selected output UOM. These certify numerical admission, not physical survey uncertainty or professional accuracy.

Manual measurements require a locator, reason and typed exact quantity and explicitly record no calibration claim. Every measurement/calibration successor preserves the previous immutable body and result. Current-use status is derived separately from original recorded facts. The present source-head policy is the current working document revision; it makes no claim about future issued drawing sets. Old facts and completed receipts remain readable under current source permissions after a new working upload, while new use requires an explicit current-source successor and verified calibration.

One immutable line binding can subsequently attach one measurement to an existing exact estimate revision/stable line. The saved authored quantity must match exactly. The binding records that the original EST-01 snapshot was not calculated from this later attachment. Net and after-takeoff-waste bases are explicit. Positive takeoff waste cannot combine with positive estimate component waste under this bounded policy. No automatic repricing or snapshot rewrite occurs. A future EST-03 acceptance manifest must include these binding identities/digests and current source/measurement/calibration eligibility; the EST-01 snapshot digest alone does not cover later attachments.

Drawing impact returns affected measurements and their exact bound estimate revision/line identities, without mutating historical results. Measurement comparison reports original and successor quantities/source/calibration changes. Catalogs authorize the same bounded candidate set before computing pagination/count/cursors and fail closed if any source cannot be verified; catalogs exceeding 500 candidates are refused rather than exposing unverified inventory.

Eight additive methods live under `cipher_aec.takeoff.api`; closed request/response types are in `schemas/api-v1.schema.json`. New writes use shared canonical-person receipts, current estimate rights and current source authority. Verification, measurement and binding DocType controllers enforce immutable exact facts and the approval effect context independently of generic permission bypass flags.
